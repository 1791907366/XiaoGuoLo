🖥️ pbootcms后台美化教程

这个教程会告诉您：包里有什么、改了什么、怎么装回去、出问题了怎么办。
全程大白话，照着做就行，一般 5 分钟搞定。

一、这个文件包里有什么

文件夹 a3后台美化文件包（以及它的压缩包 a3后台美化文件包.zip）里，一共包含 8 个文件，都是网站后台（PbootCMS 管理系统）的页面和样式文件：

包里的文件路径它是干什么的
apps/admin/view/default/index.html后台登录页面（输用户名密码的地方）
apps/admin/view/default/common/head.html后台公共头部：顶部导航栏 + 左侧菜单栏
apps/admin/view/default/common/foot.html后台公共底部：加载各种 JS 脚本
apps/admin/view/default/css/login.css登录页的样式：毛玻璃卡片、蓝色渐变按钮、动感背景
apps/admin/view/default/css/comm.css后台整体样式：卡片化布局、圆角、柔和阴影、现代蓝色主题
apps/admin/view/default/js/comm.js后台交互脚本：侧边栏显示/隐藏、菜单高亮等
apps/admin/view/default/js/mylayui.js后台功能脚本：登录验证、选项卡切换等
apps/admin/view/default/content/delecache.html“清理缓存”页面：美化了一下按钮样式

👍 简单记：包里就是“登录页 + 后台框架”的页面和样式，只动了表面外观，没有动任何数据，放心使用。

二、具体美化了哪些地方

  • 🔑 登录页：深蓝渐变背景 + 会浮动呼吸的光斑动画；登录框做成半透明“毛玻璃”卡片，带圆角和入场动画；输入框、按钮全部换成了现代风格，按钮是蓝色渐变。
  • 🧭 顶部导航栏：白色底、细边框、柔和阴影；左侧 LOGO 区深色打底，加了网站图标和版本号徽章。
  • 📂 左侧菜单栏：深色侧边栏，菜单项悬停高亮，移动端自动隐藏，和原来一样能点按钮折叠。
  • 🎨 整体风格：全后台换成统一的蓝色主题，表格、按钮、卡片都做成圆角 + 柔和阴影，字体用系统默认字体，更清爽耐看。
  • 🧹 清理缓存页：按钮改成圆角绿色胶囊按钮，悬停有轻微上浮效果。

三、怎么把美化效果装到网站里（三步）

1
先备份（强烈建议，防后悔）
打开网站目录（也就是放网站程序的那个文件夹），找到后台模板文件夹：
网站根目录\apps\admin\view\default
把整个 default 文件夹 复制一份 到桌面上，比如改名叫 default_备份。
万一以后想还原，把备份里的文件再复制回去就行。
2
复制文件、覆盖同名文件
把包里 apps\admin\view\default 下面的 8 个文件，按同样的目录结构 复制到网站目录的相同位置，提示“是否覆盖”时选 是。
例如：包的 css\comm.css → 覆盖到网站根目录的 apps\admin\view\default\css\comm.css
位置一定要放对，放错位置后台会显示不出效果。
3
清缓存 + 刷新页面
① 打开后台，点左上角“清理缓存”，把缓存清理一下；
② 浏览器里按 Ctrl + F5 强制刷新；
③ 重新打开后台地址（比如 http://您的域名/admin，把“您的域名”换成您网站自己的域名），就能看到新的登录页和后台界面啦！

四、常见问题（先别慌）

问题解决办法
页面还是老样子，没变化？多半是缓存没清干净。清一下后台缓存，再按 Ctrl+F5 强刷；也可以删除网站里 runtime/complile 文件夹下的缓存文件再刷新。
覆盖后页面乱了/错位？检查文件是不是复制到了正确位置、路径和包里一致。改错也不怕，把第 1 步的备份复制回去即可恢复原样。
后台打不开了？先看是不是文件放错了位置（多套了一层文件夹最常见）。用备份恢复后应该就正常了。
以后升级 PbootCMS 会不会变回去？有可能会，因为升级会覆盖模板文件。升级后重新按本教程复制一遍即可。

⚠️ 注意：本美化只动了后台界面的外观，不影响任何数据、会员、订单等信息。包里没有、也请不要删除或修改后台其它文件。
